# SkillSpector Runtime

This directory is the built-in runtime location for the `skill-spector` AI
publish pipeline.

The target SkillSpector source version is `2.3.7`, declared by the upstream
`NVIDIA/skillspector` `pyproject.toml`.

Runtime artifacts should be generated by the release build and unpacked here
with the current platform key:

```text
plugins/ai-pipeline/skill-spector/
  bin/skill-spector
  runtime/
    linux-x86_64/
      python/bin/python3
    linux-aarch64/
      python/bin/python3
```

The launcher never falls back to system `python3`. If the matching platform
runtime is missing, the pipeline stays unavailable when `skill-spector` is
enabled.
