# HTTP Authorization Operation Coverage

This is the live, method-level authorization inventory for production HTTP
Controllers. `ModuleAuthorizationITCase` compares every normalized `@Secured`
tuple below with the current source, so adding, deleting, renaming, or
re-annotating a protected operation requires an explicit coverage decision.

The parser column records how the HTTP resource is obtained. A specified
resource takes precedence, an explicit parser names the custom parser, and the
remaining rows use the parser selected by `signType`. The coverage column
records direct security tests or the reviewed authorization-equivalence group;
normal business behavior remains covered by the API-specific OpenAPI ITs and
scenario registries.
